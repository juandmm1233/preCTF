Qué tipo de aplicación es

Aplicación web educativa de tres capas, desplegada como conjunto de contenedores.

Cliente

SPA React 18 + Vite + TypeScript. Login, dashboard, envío de flags, modo aprendizaje y certificado. Nginx sirve el build en el puerto 80.

Servidor

API REST FastAPI con JWT (12 h). Autenticación, progresión secuencial, pistas, tokens de acceso y orquestación de laboratorios.

Estado y labs

PostgreSQL 16 para usuarios y progreso. Docker + Traefik levantan una instancia IDS por estudiante. No es un CTF competitivo embebido: es un portal de progreso.

Cómo fluye el sistema

La API es el centro: autentica, persiste progreso y habla con Docker solo vía proxy. El navegador llega al lab por Traefik, no por la API.

Tres redes Compose

prectf_app

web, api, db. Tráfico de la plataforma: el estudiante habla con la UI y /api.

prectf_socket

api y dockerproxy. Docker sin montar el socket crudo en el contenedor de la API. BUILD, EXEC y VOLUMES están bloqueados.

prectf_challenges

lab-proxy e instancias. Los labs no ven PostgreSQL ni el socket de Docker. TTL 45 min, tope 20 sesiones.

Límite de diseño

Este repositorio no copia ctf1 ni ctf2. Construye la imagen desde un contexto externo (CHALLENGE_N1_IMAGE / CTF_LAB_N1_CONTEXT).

Una instancia IDS cubre N1–N7 (distintas rutas PHP). N8 es SSH en el lab de clase. Las flags de entrenamiento deben rotarse antes de la sesión 15v15. CSRF del lab original no entra en los 8 niveles.
